# 💬 댓글 레이더 — 유튜브 댓글 & 고객반응 1초 분석기

유튜브 영상·쇼츠의 댓글을 모아 **구매의향 / 질문 / 긍정 / 불만**으로 자동 분류하고,
자주 나온 키워드·자주 묻는 질문(FAQ)·고정 댓글 문구·다음 콘텐츠 소재·AI 분석 프롬프트까지
한 화면에서 뽑는 **서버 없는 정적 웹앱**입니다.

여기에 **카피·심리학 엔진**과 **내 구독 AI 원클릭 브리지**를 얹어,
댓글에서 뽑은 반응을 8대 심리 트리거로 채점하고 지금 쓰는 ChatGPT·Claude·Gemini 구독으로
대본·반박 카드·고정 댓글을 받아오는 **카피 스튜디오**가 함께 들어 있습니다.

- 빌드 없음: `index.html`을 열면 끝 (폰트·아이콘 모두 로컬)
- 서버 없음: 수집한 댓글·설정은 이 브라우저 `localStorage`에만 저장
- 외부 요청: 사용자가 직접 수집을 누를 때 `googleapis.com`, Gemini 키를 직접 넣고 생성할 때만 `generativelanguage.googleapis.com` (트래커 0)
- 떡상 레이더(`../shortform-radar/`)와 같은 패밀리 룩 (IBM Plex Sans KR, 라이트/다크)

## 바로 쓰기

1. `index.html`을 브라우저로 연다. 데모·붙여넣기는 `file://`로 열어도 되고, **실시간 수집은 HTTP로 열어야** 합니다
   (예: `python3 -m http.server 8000`). 파일로 열면 유튜브 API 호출이 브라우저 정책에 막힙니다.
2. 첫 화면은 **데모 데이터**(꿀템 리뷰 52개 댓글)로 채워져 있습니다. 키 없이 모든 기능을 볼 수 있습니다.
3. `댓글 수집` 탭에서
   - **유튜브 실시간**: 영상·쇼츠 링크(또는 11자리 ID) + API 키 → 실제 댓글 수집
   - **데모 3종**: 꿀템 리뷰 / IT 가성비 / 재테크·썰
   - **붙여넣기**: 댓글 텍스트 한 줄에 하나, 또는 CSV(`댓글,좋아요,작성자`)
4. `반응 대시보드`에서 KPI·키워드·댓글 모음을 보고, `기획 인사이트`에서 FAQ·고정 댓글·소재·프롬프트를 복사합니다.
5. `카피 스튜디오`에서 댓글 묶음을 내 구독 AI로 보내고, 받은 결과를 채점해 고정 댓글로 바로 적용합니다.

## 기능

### 1. 실시간 댓글 수집 (BYOK)
- 입력: `youtube.com/watch?v=…`, `youtu.be/…`, `youtube.com/shorts/…`, `youtube.com/live/…`, `embed/…`, 11자리 ID
- 호출: `videos.list`(1 unit) + `commentThreads.list`(페이지당 1 unit, `pageToken`으로 최대 300개)
- 정렬: 관련도순 / 최신순 · `textFormat=plainText`
- API 키 저장 위치: `commentradar.v1.ytApiKey` (JSON 문자열).
  떡상 레이더의 `radar.v1.ytApiKey`도 자동으로 읽습니다. 두 곳에 있으면 이 앱의 키가 우선입니다.
- 오류 안내: 403 할당량 초과 / 400 키 오류 / 댓글 사용 중지 / 404 영상 없음 / 잘못된 링크
- 수집 후 원문 댓글에는 `youtube.com/watch?v=…&lc=…` 링크가 붙습니다.

### 2. 자동 분류 · 대시보드
- **4대 유형**: 구매의향·링크요청 / 질문·궁금증 / 긍정·칭찬 / 불만·아쉬움 (+ 분류 밖 `기타`)
- 한국어·영어 키워드 룰 엔진. 점수 합산 후 동점이면 `불만 > 구매의향 > 질문 > 긍정` 순으로 결정
  ("좋긴 한데 어디서 사나요?" → 구매의향, "좋은데 발열이 아쉽네요" → 불만)
- 부정 표현 보정: "안 좋아요", "좋지 않네요", "별로 좋진 않아요" → 불만
- 이모지(❤️👍🔥 / 😡👎)도 신호로 사용
- **KPI**: 총 댓글·답글·좋아요 합, 평균 좋아요, 구매의향 %, 질문 %, 긍정/부정 바
- **키워드**: 불용어·조사·서술어 꼬리를 제거하고 댓글 단위로 빈도 계산. 두 번 이상 나온 말을 우선해 최대 15개. 칩을 누르면 그 키워드가 든 댓글만 남습니다.
- **댓글 모음**: 전체 / 베스트 좋아요 TOP 10 / 구매의향 / 질문 / 긍정 / 불만 필터 + 검색(본문·작성자) + 정렬(좋아요·최신·답글) + 30개씩 더 보기

### 3. 기획 인사이트
- **시청자가 가장 궁금해하는 3가지**: 질문·구매의향 댓글을 키워드로 묶어 대표 질문 + 답변 뼈대 생성
- **고정 댓글 추천 문구**: Q1~Q3, 구매 링크 자리, 타임스탬프, 마무리 문장 + **8트리거 점수·빈틈·감점 표현 교정안**
- **다음 콘텐츠 소재 5개**: 불만·질문·구매의향 키워드에서 제목 + 이유 + 근거 개수 + 제목 점수
- **AI 심층 분석 프롬프트**: 좋아요순 댓글 50개를 구조화해 복사. "댓글에 없는 내용은 지어내지 말 것" 규칙 포함
- **내보내기**: CSV(UTF-8 BOM, 엑셀 한글 호환) / JSON

### 4. 카피 스튜디오 (심리학 + 내 구독 AI)

**① 보낼 댓글 묶음** — 수집한 댓글에서 **질문 · 구매의향 · 불만 Top**만 좋아요순으로 추립니다.
거의 같은 문장은 1개만, 닉네임은 빼고 본문만, 카테고리별 3~9개(전체 12~27개)를 글자 예산 안에서 묶습니다.
`간단 12 / 표준 18 / 넉넉 27` 중에 고를 수 있습니다.

**② 내 구독 AI로 보내기** — 묶음 + 영상 정보 + 반응 통계를 **한 장의 프롬프트**로 만들어
`[ChatGPT 열기] [Claude 열기] [Gemini 열기]` 버튼으로 넘깁니다. 누르면 프롬프트가 클립보드에 복사되고 새 창이 열립니다.
세 가지 모드:

| 모드 | 받는 것 |
| --- | --- |
| 다음 영상 대본 | 첫 3초 후킹 3안 · 5단 대본(자막·샷 지시) · 답할 질문 3개 · 마지막 CTA |
| 반박 카드 | 불만 Top 5장 — 오해 / 사실 / 근거 / 30자 반박 / 화면 지시 + "반박하지 말아야 할 불만 1개" |
| 고정 댓글 | A 정보형 · B 질문 유도형 · C 반박 예방형 (각 6줄 이내) |

프롬프트에는 8대 트리거를 의도적으로 쓰라는 지시와 함께
**"댓글·영상에 없는 사실, 수치, 가격, 재고, 날짜를 만들지 않는다 — 필요한 값은 [확인 필요]"** 규칙이 들어갑니다.

> ChatGPT Plus · Claude Pro · Gemini 구독은 **웹 로그인 상태 그대로** 씁니다.
> 이 앱이 구독 요금제를 API처럼 대신 호출하는 것은 각사 약관에서 막혀 있어, 링크로 열고 프롬프트를 넘기는 방식만 씁니다.
> ChatGPT·Claude는 주소의 `q` 파라미터로 입력창을 채우고(서비스가 보장하지 않는 기능이라, 안 채워지면 Ctrl+V),
> Gemini는 주소 자동 입력이 되지 않아 복사 + 붙여넣기입니다.

**③ 받은 결과 채점 · 적용** — AI가 준 답변을 붙여넣으면 바로 채점합니다.
고정 댓글 모드에서는 `A안/B안/C안`을 자동으로 나눠 각각 점수·빈틈·감점 표현을 보여주고,
마음에 드는 안을 **고정 댓글로 적용**(토스트에서 되돌리기)할 수 있습니다.

**④ 프레임워크 4종으로 다시 쓰기** — 댓글에서 뽑은 문제·해결·근거로 `PAS / BAB / AIDA / 4U` 카피를 만들고
완성된 카피를 엔진이 다시 채점합니다. 각 카드의 **고정 댓글 초안**을 복사하거나 바로 적용할 수 있습니다.

**무료 Gemini API 키(선택)** — 키가 없어도 위 세 버튼으로 충분합니다.
키를 넣으면 새 창 없이 이 화면에서 결과를 받습니다. 키는 `commentradar.v1.geminiKey`에만 저장하고,
화면에는 끝 4자만 표시하며, **URL이 아니라 `x-goog-api-key` 요청 헤더**로 Google에만 보냅니다.
무료 등급 모델: `gemini-3.5-flash-lite`(기본) · `gemini-3.8-flash` · `gemini-3.6-flash` · `gemini-3.1-flash-lite`.

### 5. 8대 심리 트리거 채점 (`engines/copy-psych-engine.js`)

| 트리거 | 가중치 | 보는 것 |
| --- | --- | --- |
| 손실 회피 | 15 | 놓치면/그대로 두면/되돌릴 수 없음 |
| 구체적 숫자·앵커링 | 15 | 단위 숫자, 정가→판매가, 배수, 시간 |
| 사회적 증거 | 13 | 후기, N명 선택, 재구매, 평점 |
| 권위·실측 | 13 | 실측, 데이터, 인증, 출처 |
| 호기심 갭 | 12 | 질문, 왜, 아무도 모르는 |
| 희소성·기한 | 12 | 한정, 선착순, 마감, 잔여 |
| 인지 반전 | 10 | ~하지 마세요, 반대로, 짧은 문장 |
| 초저마찰 CTA | 10 | 클릭, 무료, 3초, 가입 없이 |

점수는 가중 평균 0~100, 등급은 85+ S / 70+ A / 55+ B / 40+ C / 그 미만 D입니다.
**이 등급은 광고 카피 기준**이라, 안내문 성격의 고정 댓글은 낮게 나오는 것이 정상입니다.
그래서 화면은 등급보다 **"빈틈 2개 + 다음 한 줄"**을 먼저 보여줍니다.
감점 표현 교정은 문법·군더더기만 안전하게 치환하고, 자동 치환이 문장을 반복시키면 경고를 붙입니다.
`최고의` 같은 최상급은 사실을 만들 수 없어 치환하지 않고 대안만 제시합니다.

## 개인정보 · 보안

- YouTube API 키는 `localStorage`에만 저장하고 화면에는 `•••• 1234` 형태로만 표시합니다. 코드·파일·로그에 남기지 않습니다.
- Gemini 키도 같은 방식(`commentradar.v1.geminiKey`). 입력창은 저장 후 비우고, 요청 헤더로만 전송합니다.
- 수집한 댓글도 `localStorage`에만 저장합니다(최대 3.5MB, 초과 시 저장 생략).
- **AI로 보내는 묶음에는 댓글 작성자 닉네임·프로필·링크를 넣지 않습니다.** 본문과 좋아요 수만 씁니다.
- AI가 준 결과는 이 브라우저 메모리에만 두고 저장하지 않습니다. 새로고침하면 사라집니다.
- 외부 트래커·분석·광고 스크립트 0개. 폰트와 아이콘은 로컬 파일입니다.
- 데모 댓글은 전부 **가상 인물·가상 텍스트**입니다. 실제 영상·시청자 데이터가 아닙니다.

## 한계

- 분류는 **룰 엔진**입니다. 반어("이거 진짜 대박이네 ㅋㅋ" 같은 비꼼)나 맥락은 잡지 못합니다.
  키워드·비율은 "대략 어디에 반응이 몰리는지" 보는 용도로 쓰고, 개별 판정은 댓글 원문으로 확인하세요.
