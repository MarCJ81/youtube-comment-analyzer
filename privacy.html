개인정보 처리 방침

댓글 레이더 · 최종 갱신 2026-11-22

1. 수집하는 개인정보

없습니다. 회원가입·로그인·결제가 없고 운영자 서버가 없습니다. 분석하려고 붙여넣거나 수집한 댓글은 이용자의 브라우저에만 있습니다.

2. 저장 위치와 항목

댓글 목록, 분석 필터·설정, 직접 넣은 YouTube Data API 키가 브라우저 localStorage에 저장됩니다. 앱을 닫아도 남으며, 브라우저 저장소를 지우면 함께 삭제됩니다.

3. 외부 전송

페이지를 열기만 하면 외부 요청이 없습니다. 이용자가 API 키를 넣고 수집 버튼을 눌렀을 때만 YouTube Data API(Google)로 검색어가 전송되고, 키는 그 요청에만 쓰입니다. AI 브리지는 새 창으로 해당 서비스를 여는 방식이며 앱이 내용을 대신 보내지 않습니다.

무료 AI 맛보기. '무료로 총평 받기'를 누를 때만 영상 제목·댓글 수 요약·키워드·댓글 표본 6개가 프롬프트로 전송됩니다. 무료 체험은 Cloudflare Workers로 운영하는 무료 체험 서버를 거쳐 외부 AI 제공자(Cloudflare Workers AI, 필요하면 Google Gemini·Groq)로 전송됩니다. 서버는 프롬프트와 응답 본문을 저장하지 않고, 방문자 구분용 해시값과 그날의 사용 횟수만 남깁니다(7일 뒤 삭제). 하루 무료 횟수는 브라우저당 5회이며, 다 쓰면 안내와 함께 내 키 연결로 넘깁니다. 댓글 작성자 닉네임은 보내지 않습니다.

4. 쿠키·추적

쿠키를 쓰지 않습니다. 분석 도구·광고 픽셀·외부 트래커를 넣지 않으며, 이용 기록을 수집하지 않습니다.

5. 보관과 삭제

API 키는 앱 안의 '키 삭제'로 언제든 지울 수 있습니다. 수집한 댓글과 마지막 분석 기록은 브라우저 사이트 데이터를 삭제하면 함께 사라집니다.

6. 제3자 제공

제3자에게 제공하는 데이터가 없습니다. 운영자는 이용자의 데이터를 받지 않으므로 별도 제공·위탁이 없습니다.

7. 문의

이 앱은 정적 파일로 배포되며 운영자에게 개인정보가 전달되지 않습니다. 문의·오류 제보는 배포 페이지에 안내된 연락처나 배포 저장소의 이슈로 남겨 주세요.
